# Security Policy

## Supported versions

This repository is currently in the design phase. The `main` branch is the supported version.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Instead, contact the repository owner privately through GitHub and include:

- A concise description of the issue.
- The affected file, component, or design contract.
- Reproduction or validation steps, if available.
- Potential impact and suggested mitigation.

Reports receive an acknowledgement within seven days when contact details are available. Confirmed issues will be addressed with a coordinated disclosure plan.

## Scope

This repository contains architecture documentation and contract stubs. Threat-model observations, authority-boundary flaws, and unsafe network-contract proposals are in scope.
